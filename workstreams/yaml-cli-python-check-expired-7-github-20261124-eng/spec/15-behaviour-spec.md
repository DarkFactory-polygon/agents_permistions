# Behaviour Spec — Реестр прав агентов (локальный YAML + CLI на Python)

## Назначение и границы документа

Документ переводит требования (`10-requirements.md`, хеш в `upstream_hashes`) в наблюдаемые снаружи
сценарии поведения. Каждый сценарий описывает, что пользователь делает и что он после этого видит:
текст в терминале, код выхода, состояние файлов на диске. Устройство инструмента (модули, функции,
структуры данных, порядок внутренних проверок) сценариями не задаётся.

Собственных требований документ не вводит. Все идентификаторы `FR-NN` и `NFR-NN` — идентификаторы
требований; сценарии нумеруются `BEH-NN`. Ссылки на требования приведены в строке `traces:` каждого
сценария и в матрице трассируемости в конце документа.

## Соглашения о наблюдении

Эти соглашения действуют во всех сценариях и нужны, чтобы каждая формулировка читалась однозначно.
Они уточняют способ наблюдения и не добавляют обязательств сверх требований.

- **Вызов** — запуск CLI из терминала одной командой; наблюдаются объединённый вывод команды
  (стандартный вывод и стандартный поток ошибок) и код выхода процесса.
- **Вывод** — весь текст, который команда напечатала за один вызов.
- **«Вывод называет X»** — в выводе присутствует значение X (для полей записи — само значение поля).
  Точный формат строк, порядок слов, регистр, подписи полей и язык вывода требованиями не заданы и
  сценариями не фиксируются; сценарии проверяют наличие перечисленных сведений, а не вёрстку.
- **«Вывод отвечает "разрешено"»** и **«вывод отвечает "запрещено"»** — в выводе присутствует
  соответствующий вердикт в том виде, в котором инструмент его печатает; двух вердиктов в выводе
  одного вызова одновременно не бывает.
- **D** — локальная календарная дата компьютера в момент вызова (`FR-08`). Записи реестра в
  сценариях задаются относительно D (`D`, `D-1`, `D+7`, `D+8` и т. п.), поэтому сценарии не зависят
  от конкретного календарного дня. Единственное исключение — `BEH-25`, где локальная дата
  компьютера меняется намеренно.
- **Корректная запись** — запись о праве с пятью заполненными полями (агент, ресурс, действие, кто
  выдал, до какого числа) по формату `FR-07`.
- **Реестр** — YAML-файл прав, указанный в `--file`, либо `permissions.yaml` в текущем рабочем
  каталоге, если `--file` не задан (`FR-09`).
- Если в сценарии не сказано иное, реестр существует, читается и содержит только корректные записи.
